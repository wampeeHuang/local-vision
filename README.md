# local-vision · 本地视觉增强

> 三引擎视觉理解（MiniCPM-V本地/GLM-4.6V云端/Tesseract OCR），为纯文本模型提供"眼睛"。

纯文本 LLM 看不到图片。local-vision 是它的视觉代理——输入图片，输出结构化描述。三引擎分层：轻量 OCR 走 Tesseract，常规理解走 MiniCPM-V 本地推理，复杂场景走 GLM-4.6V 云端。


## 设计哲学

### 三层引擎 = 成本梯度
不是所有图片都需要最贵的模型看。Tesseract 免费识别文字→MiniCPM-V 本地理解内容→GLM-4.6V 云端分析复杂场景。路由逻辑基于复杂度自动选择引擎。

### 本地优先，云端兜底
隐私敏感的图片不离开本机。MiniCPM-V 的本地推理满足 80% 的常规场景，只有复杂图表、多元素关系、抽象视觉概念才走云端。

### 视觉是代理，不是替代
local-vision 给纯文本模型提供"这个图片里有什么"的结构化描述——不是替代模型的判断，是补充模型的感官。

## 诚实边界

- **本地模型精度 < 云端模型。** MiniCPM-V 在复杂图表上的准确率有限
- **RTX 5060 Ti 16GB VRAM。** 本地推理速度受限于 GPU 显存
- **不支持视频理解。** 三引擎都是图片级别的
